# Attendease – Attendance Management System

## 📌 About the Project

**Attendease** is a web-based application developed using Flutter and Dart. It aims to make attendance tracking and daily task management easier, faster, and more convenient through a user-friendly digital interface.

The website combines attendance management with a **To-Do List** feature, helping users organize their tasks and manage their daily activities in one place.

## 🎯 Objectives

- Simplify the attendance management process.
- Provide a user-friendly interface for attendance tracking.
- Help users organize and manage daily tasks using a To-Do List.
- Reduce manual work and improve productivity.
- Provide a responsive website experience across different devices.

## 🛠️ Technologies Used

- **Frontend Framework:** Flutter

## 💻 Getting Started

### Prerequisites

Install the following tools before running the project:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ramisettydurgaprasanthi-hue/attendease.git
```

**2. Navigate to the project directory**

```bash
cd attendease
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the project locally**

```bash
flutter run -d chrome
```

**5. Build the website**

```bash
flutter build web --release
```

The generated website files will be available in the `build/web` directory.

## 🌐 Deployment

The Attendease website can be deployed using Netlify or GitHub Pages.

GitHub Pages deployment can be automated using GitHub Actions to build the Flutter web project and publish the generated website files.
